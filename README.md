# Heart Rate Insights Support

This is the public issue tracker for [Heart Rate Insights](https://heart.jenny.media/), a private, local-first heart-rate analysis app for iPhone and iPad.

Use this repository to report reproducible app problems or suggest features. The app's source code is maintained privately and is not included here.

## Protect your health information

Everything posted in a GitHub issue is public. Do not include:

- Apple Health exports or CSV/PDF reports
- Screenshots containing health data
- Exact heart-rate readings, dates, or activity details
- Your name, email address, Apple ID, or other personal information

For help that requires private information, use [private email support](https://heart.jenny.media/support) instead.

## Before opening an issue

- Check whether an existing issue already describes the problem.
- Include the app version, device model, and iOS or iPadOS version.
- Describe the steps that reproduce the problem without including health data.
